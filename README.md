# React Hello World

Минимальное публичное React + Vite приложение для проверки подключения Git-репозитория к фронтенд-хостингу. На странице отображаются **Hello World** и **React is running.**

## Настройки подключения

| Параметр | Значение |
| --- | --- |
| Репозиторий | `https://github.com/MGadziev/react-hello-world` |
| Ветка | `main` |
| Корневая директория | `/` (корень репозитория) |
| Фреймворк | React / Vite |
| Node.js | 22.12+ (рекомендуется Node 22) |
| Установка зависимостей | `npm ci` |
| Команда сборки | `npm run build` |
| Директория результата | `dist` |
| Переменные окружения | Не требуются |

Это статическое приложение: после сборки хостинг обслуживает файлы из `dist`.

## Локальный запуск

```sh
npm ci
npm run dev
```

## Сборка и просмотр

```sh
npm run build
npm run preview
```

`npm run preview` предназначен для локальной проверки готовой сборки.

Версии зависимостей зафиксированы в `package.json` и `package-lock.json`. Секреты, backend и внешние API не используются.
